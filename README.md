# oily-dodo-claude-mods

A collection of Claude Code mods, one folder each.

| Mod | What it does |
| --- | --- |
| [`fall-leaves`](fall-leaves) | An autumn theme: warm colors and leaves drifting down the left side |
| [`repo-branch-band`](repo-branch-band) | Shows the remote repo and branch in a band above the prompt box |

## Install

Add the marketplace once, then install any mod from it.

At the prompt of a terminal session:

```
/plugin install fall-leaves --marketplace svilotti-od/oily-dodo-claude-mods
/plugin install repo-branch-band --marketplace svilotti-od/oily-dodo-claude-mods
```

In the desktop app: click **+** next to the prompt box, then **Plugins**,
**Add marketplace** with `svilotti-od/oily-dodo-claude-mods`, then **Add plugin**.

Start a new session afterwards to see the mod.
